*** ASDF
**** Nodejs / NPM
#+begin_src bash :async :session *install* :results silent
asdf plugin add nodejs https://github.com/asdf-vm/asdf-nodejs.git
asdf install nodejs latest
asdf set -u nodejs latest
#+end_src
** Configs
Each directory under =configs/= is a [[https://www.gnu.org/software/stow/][stow]] package.
#+begin_src bash
make install-configs
#+end_src

Local overrides go in an untracked =custom= file next to the config, e.g. =~/.config/git/custom=, =~/.config/ghostty/custom=.

*** Emacs
#+begin_src bash
cp ~/.config/emacs/docs/example.custom.el ~/.config/emacs/custom.el
#+end_src

*** Fish
Set default shell to fish.
#+begin_src text :results silent
command -v fish | sudo tee -a /etc/shells
chsh -s "$(command -v fish)"
#+end_src
